Food log, elikkäs nettisivu jonne voit kirjata ylös päivän aikana syömäsi ruoat ja niiden ravintoarvot. Sovellus on tehty niille, jotka haluavat pitää yllä terveellisiä elämäntapoja ja seurata päivittäistä syömistään ja makrojaan.

Suunnitellut toiminnot:
1 Sovellus kirjaa ylös antamasi ruoan ja makrot
2 Sovellus kirjaa tiedot alasveto laatikkoon, joissa ruoat kirjataan annetun viikonpäivän taulukolle
3 Taulukko laskee myös päivän makrot yhteen
4 Lopuksi pystyt poistamaan annetut tiedot aloittaakseen uuden viikon.
